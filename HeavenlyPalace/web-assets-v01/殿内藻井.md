# 殿内藻井：ceiling-c02

本轮优先解决殿内画面上半部的建筑细节不足。参考图的识别特征是密集朱金木构与层层退进的藻井；原资产主要由大块黛青素板、细框和简单圆纹构成。调整曝光无法补足这些缺失的形体。

已用 Blender Python 重建十二格侧间和三格中央开间：五层实体退晕、封闭背衬、盘龙浅浮雕、卷草锦地、中央分格和井字梁腹彩画。四种独立材质提供基础色、法线与 ORM 三张物理贴图。十五个开间共用两种原型，加上井字梁共七份网格。

本轮更新正式 `HeavenlyPalace_WebAssets_v01.blend` 和 `assets/architecture.glb`，清单版本字段为 `hall_ceiling_revision: ceiling-c02`。建筑压缩文件增加 88,096 字节，十二张新贴图合计 1,426,458 字节，总增量约 1.45 MiB。现有 Vite 服务直接读取正式资源，刷新后进入“殿内望云”即可验收。

## 复现

在本目录执行：

```powershell
<#
仅重建本轮藻井、导出建筑，随后压缩并核验正式资源。
完整 Hall / Quality / All 重建也复用同一藻井生成函数。
#>
./Export-WebAssets.ps1 -Stage Ceiling
./Export-WebAssets.ps1 -Stage Compress
./Export-WebAssets.ps1 -Stage Verify
```

几何入口是 `scripts/hall_ceiling.py`，材质入口是 `scripts/hall_ceiling_materials.py`。局部重建由 `scripts/refine_hall_ceiling.py` 备份、执行并核验。首次运行前的工程与资产保存在 `qa/before-ceiling-c02/`，重复执行不会覆盖这份备份。

## 验证与范围

- 藻井四十六个对象、七份共享网格；旧素板移除，重复生成无叠加。
- 主殿门洞、柱网、有效三角形、材质引用通过既有检查；安装缝追加向上射线核验。
- 独立审查用 2,135 条射线覆盖殿内顶棚，未发现贯通到屋顶的通缝。
- 压缩前后的三角形属性与实例变换一致，glTF 标准验证无错误、无警告。
- 与本轮备份逐文件比对，相机、人物、地形、植被、瀑布和环境布局保持原摘要。
- 网页生产构建与静态检查通过。未启动浏览器或执行网页截图测试。

`qa/ceiling-c02-detail.png` 是独立检查灯光下的 Blender 资产细节图，用于核对雕刻和贴图方向；网页实景的光照与视觉效果仍需人工验收。本轮集中补足藻井与梁架，白玉柱的雕刻和殿外云山尚未达到参考图的精细程度。
