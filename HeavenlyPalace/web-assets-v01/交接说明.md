# 天宫 Web 资源

正式开发入口为 `../web`，在该目录运行 `pnpm dev`，打开 http://127.0.0.1:5174/ 。

保留的交付内容：

- `HeavenlyPalace_WebAssets_v01.blend`：独立 Web 副本，原始 V9 保留。
- `assets/`：五个 GLB、实际引用的 52 张 PBR PNG、资源清单与材质说明。
- `assets/cameras.json`、`assets/environment-layout.json`：统一米制原点，Web Y-up。
- `scripts/`、`tooling/`、`Export-WebAssets.ps1`：可重复执行的资源导出、压缩与格式核验。
- `Start-WebAssets.ps1`：从已有 `web` 项目启动页面的便捷入口。

几何由约 576 万面优化至约 231 万面。浏览器已确认 290 组、7,010 个 GPU 实例；月门净径约 44 米，人物约 1.8 米。殿内使用实际 52 mm、Shift X=-0.12 的完整投影矩阵。

GLB 引用 `textures/` 中的外部图片，部署必须保留相对路径；这些 PNG 是模型材质，不能作为预览图删除。
历史预览图、对照图、调试记录、旧验证页和重复构建产物已移除。临时导出记录仅在重新导出时生成，并由 Git 忽略。

云海、水雾和瀑布动画待 Web 重建。入口五团局部云需要配合远景云海遮住屋檐，才能满足殿内望云要求，不能通过移动相机或建筑代替。细雕法线不具备原几何自遮蔽，岩壁湿润分布需结合实时水流重建。ORM 的 R=1，本轮没有场景 AO。

当前不宣称已达到稳定 30 FPS；系统 Chrome 的正式性能验收仍未完成。接入约定与导出命令见 `资源接入与复现.md`。
