# 殿内望云构图

本轮优先修正殿堂与门外风景的空间关系。原有 `hall-view-v2` 虽然使用中轴水平镜头，但梁架偏低、柱径偏粗、月门周围实墙较多；网页在超宽屏继续向两侧扩幅，门外云海的横向占比进一步下降。参考图需要让高阔柱廊与门框共同围出门外风景。

`hall-view-v3` 配合新的建筑比例取景：地坪仍为 36 米，梁架整体上抬 10 米，梁底名义高度由 80 米变为 90 米；月门圆弧半径从 22 米增加到 32 米，圆心下沉至 49 米，使地坪处的开口拓宽到约 58.5 米。门洞保持真实圆弧，并非把圆门拉成椭圆。中央柱列从横坐标 ±30 米外移到 ±39 米，相邻柱列从 ±60 米移到 ±64.5 米，24 根柱子全部保留。

第四机位仍在 Blender 坐标 `(0, 363, 39)`，焦距 28 mm，Shift X 为 0、Shift Y 调为 0.19。镜头保持水平，通过镜头上移收进抬高后的藻井，柱线保持竖直。机位位于后侧栏杆内侧，射线核验覆盖中轴、左右开口以及接近地坪的位置。

第一位人物维持 `(0, 330)` 的平面位置、1.8 米身高和 36 米脚底高度。人物用于空间尺度参照，重复运行构图脚本不会累计位移或缩放。

相机 JSON 新增 `composition_framing`。三比二及更窄画幅维持等比扩幅；从三比二到 2.4:1 逐步增加等比收紧倍率，在 2.4:1 达到 1.16 倍，之后封顶。横纵尺度同时变化，圆弧保持比例；竖向偏移围绕门口地坪的实际投影锚点调整，前景不会随着收紧被裁掉。其余相机沿用现有投影规则。

2026-09-12 已在调整后的正式 Blender 工程上完成构图核验，`qa/hall-view-v3-verification.json` 记录的实测投影结果如下：

| 构图指标 | 三比二参考画幅 | 2.4:1 超宽画幅 |
| --- | --- | --- |
| 月门最大净宽占画宽 | 37.82% | 27.42% |
| 门洞顶部距画面上缘 | 38.11% | 31.72% |
| 前方梁底距画面上缘 | 30.51% | 22.92% |
| 门口地坪以下的前景 | 22.01% | 22.01% |
| 中轴人物占画高 | 5.66% | 6.56% |

旧版月门在三比二下约占画宽 26.0%，2.4:1 下约占 16.3%。这些数字均为几何锚点的投影关系，不代表门外所有像素都无遮挡，也不等同于网页视觉验收。三进柱列按实际柱身边界核验，近柱允许切入三比二画面的边缘，形成前景框架。

## 更新与复现

相机参数集中在 `scripts/compose_hall_view.py`，建筑比例由 `scripts/hall_space.py` 提供共同常量。完整应用本轮调整时，优先在 `HeavenlyPalace` 目录执行 `Space` 阶段；它会同步建筑、机位与人物：

```powershell
# 更新主殿空间及机位，依次导出建筑和人物，再压缩并核验交付数据。
# 全部步骤使用后台 Blender 或 Node，不启动浏览器或网页截图测试。
.\web-assets-v01\Export-WebAssets.ps1 -Stage Space
.\web-assets-v01\Export-WebAssets.ps1 -Stage Compress
.\web-assets-v01\Export-WebAssets.ps1 -Stage Verify
```

`All`、`Quality` 和 `Hall` 重建时也会接入相同空间与构图，`Hall` 同步导出建筑和人物。只有已经生成本版建筑、需要单独调整相机时才使用 `View`，该阶段同步相机 JSON 并仅重导人物。`Ceiling` 用于局部藻井更新，会重新应用现有空间比例并仅重导建筑。

构图脚本使用人物当前位置计算到绝对落点的平移，重复执行不会继续移动人物。建筑模块保留原始网格和世界矩阵，重复调整先恢复基准，不会累计拉高柱子或扩大门洞。首次空间调整前的完整工程与资产位于 `qa/before-hall-space-v3/`；首次应用本版相机前的工程、相机 JSON、人物 GLB 和清单位于 `qa/before-hall-view-v3/`。

完整投影、世界矩阵、四元数、观察方向、传感器、镜头偏移与宽屏参数均写入原有 `assets/cameras.json`。网页读取相机数据，并根据实际视口应用同一套宽屏算法。更新后刷新页面，按 `4` 进入“殿内望云”。

## 检查范围

`compose_hall_view.py -- --verify` 读回已保存的工程，核验月门通视、三进内柱、人物落地与尺度，以及 JSON 与 Blender 实际矩阵及宽屏参数的一致性。报告包含四比三、三比二、16:9、2.4:1 和竖屏的投影数据，并检查圆弧不会因横纵比例不同而变形。结果位于 `qa/hall-view-v3-verification.json`。

`-- --preview` 可在明确需要时输出 `qa/hall-view-v3-preview.png`，不覆盖工程或正式资源。本轮按用户要求不启动浏览器或截图测试，界面由用户自行验收；构图脚本默认执行几何核验。云海体积、松树轮廓、细密彩画与石雕仍属于后续质感打磨，本轮重点是取景和空间比例。
