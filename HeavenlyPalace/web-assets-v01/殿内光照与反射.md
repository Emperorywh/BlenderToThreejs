# 殿内光照与反射

当前优先建立参考图中的室内外光照关系：低角度暖阳穿过柱廊，殿内阴影保留冷色天空补光，抛光石坪反射真实柱列、藻井与天空。雕刻密度、构图和远山精度仍是后续差异，本轮没有将整体画面视作已达到参考图。

## 已实施

- 日光从原先约 43.5° 仰角改到约 25.1°，来自殿内画面左前方。建筑、天空光晕、远山与云图朝向共用 `lightingProfile.ts` 中的方向。
- 使用程序生成的线性 HDR 户外天空环境替换通用展厅环境；统一曝光、降低半球补光，保留冷暖和明暗对比。
- 观察位置进入主殿附近时，将日光阴影横向覆盖缩到约 338 米；均衡画质约 0.165 米／像素，精细画质约 0.083 米／像素。原覆盖约 1280 米，均衡画质约 0.625 米／像素。离开殿内后恢复近岛覆盖，太阳方向不变。
- 在原地坪物理材质中接入真实平面反射，保留砖缝、石纹和法线。反射随视角增强，并根据粗糙度进行九点柔化；台基侧面与室外铺地不应用该反射。
- 镜像目标使用线性半浮点颜色，经过主场景统一色调映射。仅在殿内近景更新，外景回退到环境反射。静止相机下，流云倒影按均衡每秒最多 10 次、精细最多 15 次刷新；拖动镜头立即刷新，关闭动态后复用纹理。

反射会增加殿内一次低分辨率场景绘制，均衡目标为 768 × 512，精细为 1152 × 768。本轮没有进行浏览器帧率或截图测试，实际观感与性能由用户验收。该方案是实时直接光照和局部平面反射，不包含完整的多次反弹全局光照。

## Blender 射线依据

`scripts/audit_hall_lighting.py` 后台只读现有 `HeavenlyPalace_WebAssets_v01.blend`，对主殿地坪 1075 个四米间距采样点发射朝向太阳的射线。

| 方案 | 仰角 | 能见直射日光的地坪采样点 |
| --- | --- | --- |
| 原日光 | 43.5° | 12.7% |
| 采用方案 | 25.1° | 39.3% |
| 更低候选 | 19.2° | 47.5% |

采用方案兼顾殿内日照与上部柱梁的受光。数据表示采样位置的无遮挡比例，不是最终图像亮度或视觉相似度。

## 离线核验

在本目录按顺序运行；Blender 路径可按本机安装位置替换：

```powershell
# 后台读取真实建筑，生成太阳方向及地坪高度检查结果。
# 不保存 Blender 工程，也不启动浏览器或产生界面截图。
& 'D:\app\blender\blender.exe' --background HeavenlyPalace_WebAssets_v01.blend --python-exit-code 1 --python scripts/audit_hall_lighting.py
node tooling/verify-hall-lighting.mjs
& 'D:\app\blender\5.2\python\bin\python.exe' scripts/verify_hall_shaders.py
```

驱动核验使用既有 `qa/cloud-sea/python` 中的 `moderngl`。若在新电脑上重建，可先用所选 Python 安装依赖到该目录：

```powershell
# 仅安装离线核验所需的独立上下文依赖，不增加网页运行时依赖。
# 后续核验脚本从该忽略目录读取模块。
& 'D:\app\blender\5.2\python\bin\python.exe' -m pip install --target qa/cloud-sea/python moderngl
```

检查报告位于忽略目录 `qa/hall-lighting/`：太阳射线、阴影覆盖、反射物理射线对应、画质切换、外景停用、异常状态恢复，以及四种生产着色器的驱动编译与链接。网页另运行 `pnpm run build` 和 `pnpm run lint`。

## 页面验收

1. 按 `4` 进入“殿内望云”，检查左前方暖光、柱列长影、柱脚接地和地面的柱列倒影。
2. 轻微拖动、缩放镜头，检查倒影随真实几何移动，砖缝仍稳定贴合地坪；降低或抬高观察角度时反射强度应自然变化。
3. 切换均衡／精细画质、关闭动态、切回三个外景，确认场景无闪烁、裁剪残留或地面突然消失。
