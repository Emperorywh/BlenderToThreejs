# 殿内望云 · 月门外环境

当前版本为 `cloud-sea-v2-moon-gate`。本轮优先建立月门外的纵深：近处云浪、中景岩壁古松、露出云冠的破碎山脊，以及保留蓝天的远处空气透视。

旧 `terrain.glb` 中仍有 92 个专用远山网格，它们距离较近，尖锥轮廓挡在新云海前方。网页在新环境完整加载后，按专用材质停用这批占位对象。主岛、桥台、建筑、人物与正式机位沿用当前资产。

## 资产与实现

- `HeavenlyPalace_CloudSea_v01.blend`：可编辑体积云、环绕山脊、岩壁古松、日光、殿内机位及低位云床参照。
- `scripts/build_cloud_sea.py`：体积材质、Cycles 图集烘焙、云浪布局与工程保存入口。
- `scripts/moon_gate_landscape.py`：确定性生成破碎峰群、近景岩壁、曲线枝干和实体针叶簇。树根与灌木落点来自实际岩壁射线。
- `assets/cloud-sea/cloud-atlas.png`：3072 × 1536，单格 768 像素，四种云形、平视与俯视两行；96 采样烘焙，标准 sRGB、非预乘透明度。
- `assets/cloud-sea/layout.json`：732 个云团、三圈山脊、三种近景网格与替换标记。坐标为米制 Y 向上。
- `../web/src/scene/cloudSea.ts`：天空、云床、云片实例、岩松受光、空气透视、旧山群替换与资源释放。

主云床位于 -560 米。门外六排云浪约在 1.35、2.25、3.7、6.1、9.8、15.7 公里处，角尺寸逐层缩小。山群分布在约 5.3、9.7、16.3 公里处，并延伸到其他方向供环游观察。右侧古松岩壁位于世界负 X、约正 Z 1.7 公里处；对殿内向正 Z 的相机，负 X 对应画面右侧。

入口中央屋面位于正 Z 175～209 米、顶高 44.5 米。原五团遮檐云偏向旧机位一侧，现以正 Z 151 与 166 米两排薄云替换，并按正式眼点横向居中。加入保留的岛边云与瀑布水雾后，网页共绘制 819 个云实例。

云海使用离线体积光照图集与实时空间布局。岩壁、山脊、枝干和针叶均为真实三维网格；云团仍是按观察方向投影的图集云片，靠近或穿入云团时具有这种表示方式的限制。独立 Blender 工程保留真实体积材质，可继续编辑与烘焙。

## 重建

在仓库根目录执行：

```powershell
# 完整生成当前分辨率的图集、云层布局、岩松山脊和独立工程。
# 体积材质或烘焙灯光发生变化时使用此命令，输出到原云海资源入口。
& D:/app/blender/blender.exe --background --factory-startup --python-exit-code 1 --python HeavenlyPalace/web-assets-v01/scripts/build_cloud_sea.py -- --tile-size 768 --samples 96

# 只修改布局或几何时复用图集，仍重新保存完整的可编辑云海工程。
# 图集尺寸从实际文件读取，避免布局参数与已经烘焙的像素尺寸不一致。
& D:/app/blender/blender.exe --background --factory-startup --python-exit-code 1 --python HeavenlyPalace/web-assets-v01/scripts/build_cloud_sea.py -- --skip-bake
```

默认尝试本机 OptiX，无法使用时回退 CPU。中间 EXR 和报告位于忽略的 `qa/cloud-sea/`。开发服务器直接读取正式资源目录；发布版本需在 `web` 目录重新执行 `pnpm run build`，由构建流程复制资源。

## 离线核验

```powershell
# 只读打开当前建筑工程，核验云图集、三角形、门洞构图、树根接触和入口屋面遮挡。
# 入口屋面检查使用实际建筑三角形；此过程不创建浏览器或生成界面截图。
& D:/app/blender/blender.exe --background HeavenlyPalace/web-assets-v01/HeavenlyPalace_WebAssets_v01.blend --python-exit-code 1 --python HeavenlyPalace/web-assets-v01/scripts/verify_cloud_sea.py

# 使用真实网页模块核验旧远山替换、四机位排序、取消与资源回收。
# 同时导出生产着色器，供本机驱动在独立上下文中编译。
node HeavenlyPalace/web-assets-v01/tooling/verify-cloud-sea.mjs

# 当前核验环境已在忽略的 qa 目录安装 moderngl，未修改网页运行依赖。
# 该编译检查不启动浏览器或可见窗口。
& D:/app/blender/5.2/python/bin/python.exe HeavenlyPalace/web-assets-v01/scripts/verify_cloud_shaders.py
```

本轮检查结果：

- 八格图集的透明边界、实体核心与明暗对比通过。
- 三圈山群共 43,160 个三角形，岩壁古松共 28,006 个三角形；索引、法线与三角形面积通过。
- 门洞云冠覆盖约 39.2%，右侧岩松覆盖约 11.8%；上部指定蓝天区域未被云片覆盖。
- 入口屋面 9,312 个三角形中心采样均被其前方薄云遮住；树根接触检查通过。
- 92 个旧远山网格被精确停用，主岛及混合材质网格保留。
- 四机位实例排序、异步取消、迟到纹理回收、九组着色器的本机驱动编译通过。
- `pnpm run build` 与 `pnpm run lint` 通过。

覆盖率和遮挡率是基于当前正式相机、几何与图集的离线估算，不代表网页截图测量。刷新网页后选择“殿内望云”或按 `4`，检查云浪层次、右侧岩松、山脚入云及月门底部遮檐效果，再切换其余机位和环游。未启动浏览器截图测试，最终观感、帧率与交互由用户手动验收。
