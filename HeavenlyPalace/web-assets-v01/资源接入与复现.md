# 资源接入与复现

## Web 接入

正式源码位于 `HeavenlyPalace/web/src`，开发时通过 `/palace-assets/` 读取本目录 `assets/`。
`pnpm build` 自动生成包含模型与贴图的 `web/dist/`，部署整个目录即可。

五个 GLB 按建筑、地形、植被、人物、瀑布拆分，使用 `GLTFLoader` 和 `MeshoptDecoder`。
保留 `EXT_mesh_gpu_instancing` 创建的 `InstancedMesh`，不要展开为数千个普通 Mesh。

全部 Web 数据采用米制与同一原点，Blender `(x,y,z)` 已转为 Web `(x,z,-y)`，不要再次居中或旋转。
相机世界/投影矩阵为列主序，可直接传给 `Matrix4.fromArray()`。固定 4:3 机位使用完整投影矩阵和逆矩阵。
殿内焦距 52 mm、Shift X=-0.12，垂直 FOV 约 29.1°；镜头偏移已包含在矩阵中，不能直接将 Shift 作为 filmOffset。

Base Color 使用 sRGB，Normal/ORM 使用线性数据；ORM 的 R=1、G=粗糙度、B=金属度。
法线为 glTF +Y，并有 MikkTSpace 切线；柱纹使用 UV1，玉石使用 UV0。
环境 JSON 区分远景云海、近岛云雾、五团入口遮檐云及瀑布水雾。
瀑布材质 `WEB_Waterfall_Static_Preview` 保留几何，出水口、路径和流向可用于后续动态材质。

## 重新导出

需要 Blender 5.2、Node.js/npm，原件位于上级 `stage1/HeavenlyPalace_Detail_v09.blend`。
在 HeavenlyPalace 根目录运行：

```powershell
# 重建副本、烘焙适配与基础导出。
# 修改程序材质时追加 -Rebake，普通重复导出会复用现有贴图。
.\web-assets-v01\Export-WebAssets.ps1 -Stage All
.\web-assets-v01\Export-WebAssets.ps1 -Stage Compress
.\web-assets-v01\Export-WebAssets.ps1 -Stage Verify
```

只修改 Web 副本时可先用 `-Stage Export`，随后压缩和核验。
首次压缩或核验时自动通过锁文件安装 `tooling` 依赖；这些依赖不纳入 Git。
脚本针对本 V9 的实际对象命名，不能视作任意 Blender 项目的通用转换器。

`qa/` 与日志是按需生成的导出中间数据，已被忽略，可随时清理。需要导出时会自动重建目录与必要审计。
导出只保留最终 GLB 引用的纹理；基础色不包含直接光照、高光或 AO。
导出后运行 `web` 的 `pnpm dev` 检查四机位与材质，再运行 `pnpm build`。
